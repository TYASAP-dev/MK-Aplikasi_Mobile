# Kasir Kedai Kopi

Program sederhana untuk menghitung total pembayaran di kedai kopi menggunakan Dart.

# Aturan

- Belanja minimal Rp100.000 mendapat diskon 10%.
- Member mendapat diskon 15%.
- Jika tidak memenuhi syarat, tidak mendapat diskon.
- Potongan maksimal Rp25.000.

# Contoh

```dart
print("Total bayar: Rp${hitungPembayaran(50000, false)}");
print("Total bayar: Rp${hitungPembayaran(100000, false)}");
print("Total bayar: Rp${hitungPembayaran(150000, true)}");
```
